# Parity Gap: `rebalancing-client` vs `rebalancing-engine`

Date: 2026-08-16

This document outlines the gaps between the current state of `rebalancing-client` (CLI) and the latest `main` branch of `rebalancing-engine`.

## 1. API Features & Commands
The `rebalancing-engine` API surface has expanded significantly with Live Agent functionality (Tranches 2-4). The client lacks commands to interact with these new capabilities:

### Missing Endpoints
- **Portfolio Summary**: `GET /api/portfolios/summary`
- **Trigger Rebalance**: `POST /api/portfolios/:id/trigger-rebalance` (with `dryRun: boolean`)
- **Circuit Breaker**: `POST /api/portfolios/:id/circuit-breaker/reset`
- **Cashflows**: `POST /api/portfolios/:id/cashflows`
- **Events Stream**: `GET /api/events/stream` (SSE for real-time updates)
- **Queue Management**: `GET /api/queue/status`, `POST /api/queue/process-batch`, `POST /api/queue/models/:id/fan-out`
- **Admin Endpoints**: Tenant, user, and asset management (`/api/admin/*`)
- **Models Endpoints**: `GET /api/models`, `POST /api/models`

## 2. Types and Data Structures (Typescript)
The engine OpenAPI specification has been updated with new types/enums that the client does not yet reflect in `src/types.ts`:
- `strategyType`: Now includes `tax_aware_us`.
- `Portfolio`: Now includes `taxJurisdiction: string`.
- `CircuitBreakerState` and `DriftBreakdown`: Need tightening (Issue #25) on both, but engine typing also diverged.

## 3. Dependencies
- The client has several open Dependabot PRs updating core tooling (TypeScript 7.x, ESLint 10.8.x) which the engine has already adopted.

## 4. Documentation
- The `README.md` for the client only documents read-only commands (`portfolios list`, `drift`, `logs`, `prices`). It needs updating for any new write/admin commands introduced.
